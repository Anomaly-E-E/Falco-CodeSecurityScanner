## 🌌 Overview
**Falco** is a next-generation vulnerability scanner built for developers.  
It analyzes your code for potential security flaws like **SQL Injection**, **XSS**, and **Insecure Configurations**, then provides actionable insights — fast, elegant, and developer-friendly.

> 🧩 Designed for clarity.  
> ⚙️ Powered by Node.js, React, and Supabase.  
> 🧠 Enhanced by intelligent pattern recognition and AI-based analysis.

---

## 🧠 Core Features

| Feature | Description |
|----------|--------------|
| 🔒 **User Authentication** | Secure login, registration, and email verification. |
| ⚡ **Real-Time Scanning** | Detect vulnerabilities instantly as you upload or paste code. |
| 📊 **Dashboard** | Interactive dashboard to view and manage your security scans. |
| 💰 **Credit System** | Users receive limited scan credits with optional upgrades. |
| 📧 **Email Verification** | Seamless verification flow with Nodemailer & Supabase. |
